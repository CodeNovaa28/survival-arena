Fix the hit detection so that the **actual logical hitbox matches the visible target section**.

Requirements:

* The visible target section and the logical success zone must be aligned.

* If it is outside the section, it should count as a loss.
* Account for the moving line's actual width rather than checking only a single mathematical point if appropriate.
* Remove timing/frame-rate sensitivity that causes visually correct clicks to fail.
